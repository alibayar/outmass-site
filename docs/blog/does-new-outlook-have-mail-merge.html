Does the New Outlook Have Mail Merge? What Works Today

Published August 24, 2026 · 8 min read

Every answer you find to this question disagrees with the last one. Some pages say mail merge is gone from Outlook, some say it arrived in 2025, some say it lands "early 2026." Meanwhile people whose merges worked last month are watching Word open a copy of Outlook they no longer have.

So this page does something simple: it separates what ships today from what is on the roadmap, and it cites Microsoft for both.

Short version. Classic Outlook for Windows still does full Word-driven mail merge. New Outlook and Outlook on the web have a basic mail merge that gives each recipient their own copy of the message, and Word-driven merge does not work there at all. The personalized version — Microsoft calls it Mail Merge (Advanced) — is roadmap item 423047, currently listed as preview in August 2026 and general availability in September 2026, status "In development."

Why your Word mail merge stopped working

This is the most common version of the question, and it has a precise answer. Word's mail merge talks to Outlook through MAPI, an interface that only classic Outlook for Windows provides. New Outlook does not expose it. A moderator on Microsoft Q&A — badged "Microsoft External Staff" — puts it directly: mail merge in Word "depends on MAPI integration, which is only available in the classic Outlook for Windows. The New Outlook does not currently support this feature, so when you start a Mail Merge, Word will attempt to open Outlook (classic). This is expected behavior."

Nothing is wrong with your Word document or your Excel list. If you need Word-driven merge back today, the workaround given in that thread is to switch the Try the new Outlook toggle off and run the merge from classic Outlook.

Microsoft's own feature comparison between new Outlook and classic Outlook puts it in one line: mail merge is Available in classic Outlook and Partially Available in new Outlook — and the link on that row points straight at the roadmap item below.

What mail merge in new Outlook does today

The version shipping now is Mail Merge (Basic). Microsoft's instruction is to open a new message and pick Start mail merge from the Send dropdown. What it does is give every recipient their own copy of the email, addressed only to them — so nobody sees the whole list. Think of it as a better BCC.

What it is not, yet, is personalization. There is no data file to import and no per-recipient fields: you address the message the way you address any other, and everyone gets the same body. That difference — one identical message versus a message that greets each person by name — is exactly what the Advanced version is meant to add.

What Mail Merge (Advanced) is supposed to do

Here is the roadmap description, from Microsoft 365 roadmap item 423047, "Outlook: Mail Merge (Advanced) on Outlook on the Web and new Outlook for Windows":

"Mail Merge (Basic) will be improved upon to allow fields to be replaced by values per email address. When Mail Merge (Advanced) is launched, not only will every recipient receive their own email with only their email address in the recipients list, but the emails can further be personalized to include content such as their name."

Current state of that entry, checked on 24 August 2026: status In development, preview August 2026, general availability September 2026, last modified 29 May 2026. Platforms named are Outlook on the web and new Outlook for Windows.

Treat those dates as a plan, not a promise. The entry has been revised more than once since it appeared, and a good deal of the coverage you will find still quotes earlier dates that have already come and gone. We re-check the roadmap rather than repeat an old article, and we date this page when we do.

What Microsoft has not said

This is the part most pages fill in with guesses, so here is the honest version. Across the roadmap entry, Microsoft's support documentation and answers from Microsoft Q&A moderators, we could not find any statement about whether Mail Merge (Advanced) will include:

  • open or click tracking
  • detection of who replied
  • automated follow-ups
  • pacing or throttling controls of its own
  • unsubscribe handling, bounce processing or complaint handling
  • campaign reporting

Not "Microsoft says no" — Microsoft says nothing. The same is true of which data sources it will import from and which licences will receive it. Anyone who tells you the finished feature will or will not do these things is guessing. We will update this page when Microsoft publishes more.

The limits that do not change either way

Whatever the merge button ends up doing, the mailbox underneath it has the same ceilings. From Microsoft's Exchange Online limits service description:

LimitValue
Recipient rate limit10,000 recipients per rolling 24 hours, per mailbox
Recipient limit per messagecustomizable up to 1,000 recipients (many mailboxes default to 500)
Message rate limit30 messages per minute

There is also a tenant-wide external recipient limit tied to your licence count, documented by the Exchange team. Personal Outlook.com accounts have their own published limits, and Microsoft notes they vary with account history.

Two different ceilings explain two different symptoms. Go faster than 30 messages a minute and the excess is held back and carried into the following minutes — the send crawls rather than stops. Pass the daily recipient ceiling and the rest of the batch stops going out until the 24-hour window rolls; that is the one people meet on day two of a big send. We wrote the full arithmetic up in Outlook's send limits explained.

Microsoft's guidance on that same page is blunt, and it is fair: customers "who need to send legitimate bulk commercial email (for example, customer newsletters) should use third-party providers that specialize in these services." If you are sending a newsletter to 50,000 strangers, a mailbox is the wrong tool and no merge button will fix that. If you are sending 200 personalized emails to people who know you, from the address they recognise, the mailbox is exactly right — you just need something around it.

Questions people actually ask

Does the new Outlook support mail merge using Word and Excel?

No. Word's merge needs MAPI, which only classic Outlook for Windows provides. Word will try to launch classic Outlook when you start the merge; if you no longer have it, the merge cannot complete.

Is mail merge being removed from Outlook permanently?

There is no Microsoft statement saying that. Classic Outlook still lists mail merge as available, and the roadmap has an item explicitly about extending the new Outlook version rather than retiring it.

I can see a mail merge option in new Outlook but it will not send. What is wrong?

The basic version has been reported to fail in some tenants and configurations, and Microsoft's own community threads carry those reports. If it will not send for you, the reliable routes today are classic Outlook for a Word merge, or a tool that sends through Graph from Outlook on the web.

Can I do a mail merge in the web version of Outlook?

You can send each person their own copy with the basic feature. For personalized content per recipient — names, companies, any column from your own list — you need Mail Merge (Advanced) when it ships, or an extension that does it now.

Why were my mail merge emails not received?

The usual culprits are Microsoft's sending limits — messages held back once you pass 30 a minute, or a daily recipient ceiling reached after a big send — or a large identical send being filtered. Sending at a controlled pace from your own mailbox, with an unsubscribe link and a clean list, is what keeps that from happening.
