How to Send a Mass Email Individually in Outlook (2026)

Published September 15, 2026 · 6 min read

You have one message and a list of people. Put the addresses in To, or add a contact group, and everyone can see everyone else. Microsoft says a personal distribution list cannot be shown in the To box without letting recipients expand it to every name and address.

Bcc hides the list, but it is still one message to many people, with the same words for everyone. For an email that arrives the way a message to one person does, each person needs a separate message. There are a few ways to do that from Outlook, and they look different when they land.

Short version. Same text for everyone, in new Outlook for Windows or Outlook on the web: use Start mail merge from the Send dropdown, and each person gets their own copy with no other recipients listed. Each person's name or details in the message: Word's mail merge with classic Outlook, or a tool like OutMass in Outlook on the web. Bcc only hides the list.

Same message, sent separately: Start mail merge in new Outlook

For the same text to everyone, the built-in option in new Outlook for Windows and Outlook on the web is enough. The steps, from Microsoft's new Outlook tips for executive admins and delegates:

  1. Start a new mail.
  2. Open the dropdown on the Send button.
  3. Select Start mail merge.

Microsoft says every recipient will receive "their own copy of the email without other recipients listed." There are no per-person fields, so everyone reads the same words. What the feature does today, and what Microsoft has said about a personalized version, is on our page about mail merge in new Outlook.

Separate and personalized in classic Outlook: Word's mail merge

Microsoft's instructions for sending email with Word's mail merge say Word sends a separate message to each address in your list and that you cannot add anyone in Cc or Bcc. You cannot attach files, though you can include links. Fields from your mailing list, such as a greeting line, make each message personal.

The catch is the email program. Word needs a MAPI-compatible email program installed, and new Outlook does not provide MAPI, so the merge will not run from it: an answer from Microsoft External Staff on Microsoft Q&A says Word tries to open classic Outlook instead (why that happens). Word for the web cannot run a merge either. On a Mac, Microsoft notes that Merge to E-Mail is unavailable until you have selected a default email program, such as Outlook for Mac.

The full Word and Excel steps are in mail merge in Outlook, the native way.

Why Bcc is not the same thing

Bcc does one job well: recipients cannot see each other's addresses. Microsoft's advice for keeping a personal distribution list private is your own address in To and the list in Bcc. But it is still one message, and everyone gets identical text.

Bcc addresses also count toward the per-message limit. Microsoft's Exchange Online limits count the To, Cc and Bcc fields of one message together, customizable up to 1,000 recipients. Outlook.com lists 500 recipients per message for Microsoft 365 subscribers, and lower limits for non-subscribers. Microsoft's outbound spam guidance for mass mail through Microsoft 365 recommends staying within the sending limits, which it says includes avoiding large Bcc lists.

What Bcc costs against those limits, and how contact groups differ from lists your administrator makes, is covered in what Bcc really does and the four kinds of list.

How to check it really went out individually

Put yourself on the list before trusting any method with a real one.

  • Start mail merge: include your own address, then check that the To line on your copy shows only you.
  • Word's mail merge: add a row with your address and send just that record first, using the Send records option.
  • OutMass: use Test Send. After the real send, each person is a separate item in your Sent Items.

If your copy shows anyone else in To, it went out as one shared message.

Sending individually does not raise Microsoft's limits

Separate messages still count toward the daily limit. Exchange Online counts every recipient you send to in a 24-hour period, across all your messages, so 200 separate emails to 200 people use the same allowance as one email to all 200. The numbers by account type are in Outlook's send limits explained, and the other ways to send mass email from Outlook are in our step-by-step guide.

Questions people actually ask

Can I send a mass email in Outlook without Bcc?

Yes. In new Outlook for Windows and Outlook on the web, Start mail merge in the Send dropdown gives each recipient their own copy with no other recipients listed. In classic Outlook, Word's mail merge sends a separate message to each address and can add each person's details from your list.

How do I make a mass email look like it was sent to one person?

Send each person a separate message. Start mail merge does that with the same text for everyone. Word's mail merge in classic Outlook, or OutMass in Outlook on the web, can also add each person's name or other details from your list.

Why can everyone see the other addresses?

The addresses went in To or Cc, typed in or added through a contact group. Microsoft says a personal distribution list cannot be shown in the To box without letting recipients expand it to every name and address. Put the group in Bcc, or send each person a separate message.

Does sending separately get around Outlook's sending limits?

Only the per-message limit, because each message has one recipient. Microsoft's daily limit counts recipients across all your messages, so 200 separate emails to 200 people use the same daily allowance as one email to all 200.

Will a big Bcc email be flagged as spam?

Microsoft's guidance does not give a yes or no. Its outbound spam guidance for mass mail through Microsoft 365 says to stay within the sending limits, including avoiding large Bcc lists, and says marketing email should always offer a way to unsubscribe.
