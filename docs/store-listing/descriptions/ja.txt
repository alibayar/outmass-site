--- DESCRIPTION (1425 characters) ---
Outlook Web をプロ仕様の一括メール送信ツールへ。OutMass はメール差し込み、トラッキング、フォローアップ、AI による文面作成を outlook.office.com と outlook.live.com の中に直接もたらします。Microsoft 365 と個人 Outlook.com アカウントの両方に完全対応。

✨ できること

📧 CSV からのメール差し込み — {{firstName}}、{{company}} など任意の列でパーソナライズ
🎯 件名の A/B テスト(Pro) — コンバージョンする件名を見つける
⏰ 予約送信(Starter+) — 今すぐ作成し、最適なタイミングで配信
🚦 1 日の送信上限 — 1 日に送るメール数に上限を設けて、送信者としての評価を守る
♻️ 自動再開 — キャンペーン途中で月間の上限に達しても、リセット後に残りを自動送信
🔁 自動フォローアップ(Pro) — 開封しなかった相手に再アプローチし、すでに返信した相手はスキップ
📚 テンプレートライブラリ(Starter+) — ベストコピーを保存・再利用
🤖 AI メールライター — 短い指示からメール文面を作成(Pro、月 50 回)
📊 開封・クリック追跡 — ピクセル、クリック、配信停止リンク
📎 OneDrive 添付 — 重い添付ファイルの代わりに OneDrive リンクで共有。配信性が向上、大容量ファイル可、受信者の閲覧分析も可能。
💬 返信検出 — 毎日の受信トレイスキャンで本物の返信を検出 — 開封やクリックを超える最強のエンゲージメント指標。
📈 キャンペーンレポート — 開封率・クリック率、完全 CSV エクスポート
🌍 13 言語の UI — アラビア語 RTL 対応を含む

• Outlook で差し込み印刷を試して挫折した経験がある方

🔒 あなたのアカウント、あなたの送信

OutMass はあなた自身の Microsoft アカウントから、OAuth 2.0 と公式の Graph API を使って送信します。第三者の送信サーバーも共有 IP プールも使わないため、受信者にはあなたからの通常のメールとして届きます。キャンペーンは当社サーバーに保存されます。予約送信、フォローアップ、キャンペーンレポートは保存なしでは動作しないためです。返信検出が記録するのは返信が届いたという事実だけで、その本文を記録することはありません。
