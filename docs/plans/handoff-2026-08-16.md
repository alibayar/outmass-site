## What today taught

- **The artifact is the ground truth.** The published zip corrected the
  commit archaeology (the changelog had been rebuilt around the wrong cut
  point); Ali's upload memory corrected the Edge-review estimate a
  handoff's dates implied. Records describe when things were written;
  artifacts describe what shipped.
- **A "done" without writers is not done.** The audit's verify agent
  called the anchor column fixed; two skeptics found nothing ever wrote
  it. The fix that makes a defect unreachable and the fix that merely
  makes it invisible read identically in a diff summary.
- **Your own day-old fix is the review's best target.** The account-switch
  hygiene write (a2e13df) backfired on same-account consent flows; the
  "not equal" plan filter shipped where "above" was specified. Both were
  caught only because the review treated fresh work as hostile.
- **A blocker can be live and unhit.** The prorated-upgrade misreport sat
  in production 0.2.1 the whole time; telemetry showed zero upgrade
  clicks, so the window closed before any customer fell through it. The
  telemetry check is what turned "ship the fix urgently" from panic into
  a sentence.
- **Silence has two shapes.** 030/031 proved themselves by crashing-if-
  absent; 028/029 could not, because their readers fall back politely.
  Verification effort belongs on the polite ones.
